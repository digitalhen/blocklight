01 / SIMPLE MAP

Start with the buildings.

A small GeoJSON file, a camera, and a theme.
The simplest way to put a city on the page.

Give #map a height and load the MapLibre CSS and worker.
Local preview · package not published yet

import { createCityMap, buildings } from 'blocklight';
import { nyc } from 'blocklight/nyc';

const city = createCityMap({
  container: 'map',
  city: nyc,
  theme: 'blueprint',
  pitch: 57,
});

city.addLayer(buildings({
  id: 'buildings',
  source: '/data/buildings.geojson',
  heightProperty: 'height_m',
}));
02 / DATA-DRIVEN MAP

Add a city’s worth of 311.

Load citywide geometry by viewport. Join a separate JSON file to individual buildings, color by request count, and render details on click.

2025 HPD housing requests · all five boroughs
Geometry and data files built with npm run data:city
Keep the city setup above; replace its addLayer call.
Connect select and details to your own UI elements.

import { addBuildingDatasets, steppedScale } from 'blocklight';

const data = {
  url: '/data/311-citywide.json', records: 'buildings',
  join: { feature: 'source_id', record: 'buildingId' },
};
const layer = await addBuildingDatasets(city, {
  source: '/data/city-buildings.json',
  datasets: [
    {
      id: 'housing', label: 'All housing requests',
      data: { ...data, aggregate: { op: 'sum', field: 'count' } },
      color: steppedScale('value', [
        { value: 0, color: '#26354d' },
        { value: 1, color: '#e8c98a' },
        { value: 20, color: '#bc6447' },
      ]),
    },
    {
      id: 'heat', label: 'Heating / hot water',
      data: { ...data, aggregate: {
        op: 'sum', field: 'categories.HEAT/HOT WATER', missing: 0,
      } },
      color: steppedScale('value', [
        { value: 0, color: '#26354d' },
        { value: 1, color: '#eac197' },
        { value: 20, color: '#d97040' },
      ]),
    },
  ],
});

// Wire your own selector to the controller.
select.onchange = () => layer.setDataset(select.value);
city.on('select', selection => {
  details.textContent = `${layer.getValue(selection?.feature)} requests`;
});
